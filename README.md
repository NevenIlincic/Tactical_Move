# Tactical Move (in development)
- Tactical Move is Door Kickers inspired strategy game. Goal is to eliminate all enemy soldiers.
- An enemy soldier is only visible if he is in the field of view (FOW) of at least one player soldier.
- You can select the player with which you want to interact.
- For now, you can only draw the path for your soldier should take, the point/direction he should face when moving and the direction to turn when he reaches the desired point.
